## أهلًا 👋

I'm a software engineer based in Riyadh. I build mobile apps and the services behind them. I enjoy figuring out how systems fit together and how to make them easier for the next developer to change, test, and ship.

- **📱 Mustahaq** started because I kept forgetting which salary advances I’d already paid. I built an Arabic-first Flutter app to track them. One of my favorite details is a small one: the arrows point the way you expect when you move between months.
- **☕ NFC experiments** started with a coffee machine, a 3D printer, and a stack of blank tags. I’m exploring whether tapping a physical recipe card can tell the machine what to brew.
